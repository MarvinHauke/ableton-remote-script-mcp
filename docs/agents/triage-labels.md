# Triage Labels

| Label in mattpocock/skills | Label here        | Meaning                                  |
| -------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`    | Needs evaluating                         |
| `needs-info`               | `needs-info`      | Waiting on the user for more information |
| `ready-for-agent`          | `ready-for-agent` | Fully specified, ready for an agent      |
| `ready-for-human`          | `ready-for-human` | Needs the user (e.g. anything in Live)   |
| `wontfix`                  | `wontfix`         | Will not be actioned                     |

A label is a bracketed tag at the start of a `docs/feature-plans/STATUS.md` line, e.g.
`- [ready-for-agent] extractor misses class bases…`.
